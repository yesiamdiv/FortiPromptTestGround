# Agentic LLM Adversarial Testbed - Sessions System

This component of the Agentic LLM Adversarial Testbed (ALAT) is responsible for managing and persisting the state of individual testing workflows.

## Features

*   Create, load, save, and delete independent test sessions.
*   Encapsulate specific settings, parameters, and progress for each testing scenario.
*   Enable systematic and reproducible research into AI agent security.
